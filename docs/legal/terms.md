# 利用規約

制定日: 【公開日】

この利用規約（以下「本規約」）は、山﨑悠樹（以下「運営者」）が提供する「家系ラーメンを探す」（以下「本サービス」）の利用条件を定めます。本規約は、本サービスのすべての利用に適用されます。本サービスを使う前にお読みください。

## 1. 本サービスの内容

本サービスは、Claude・ChatGPT などの AI アシスタントの中で、家系ラーメンの店を探す・地図で見る・候補を 3 軒に絞る・まわる順番を考える・行った店を記録する、といった機能を提供します。料金はかかりません。

## 2. 店の情報について

- 店の情報は、OpenStreetMap の協力者が入力したデータを元にしています（© OpenStreetMap contributors、ODbL）。**閉店・移転・営業時間の変更が反映されていないことがあります。** お出かけの前に、店の公式の情報をご確認ください。
- **「家系」かどうかは推定です。** 店名や登録された説明から判定し、「家系」「家系の可能性」「家系か未判定」の 3 段階で表示しています。
- **味の傾向は参考です。** 一部の店について、既知の系列から割り当てているだけで、店ごとに確かめたものではありません。
- 本サービスは、店の評価・人気・混雑・待ち時間の情報を持っていません。
- 表示する距離は**直線距離**です。歩く道のりや所要時間ではありません。
- AI アシスタントが本サービスの結果について話す内容は、AI アシスタントが生成したものです。運営者はその正確さを保証しません。

## 3. サインインと訪問記録

- 「行った」の記録を使うには、Google でサインインする必要があります。ほかの機能はサインインせずに使えます。
- 記録の扱いは、[プライバシーポリシー](privacy-policy.md)に定めます。
- 利用者は、いつでも記録を削除できます。

## 4. 禁止事項

本サービスの利用にあたり、次のことをしてはいけません。

1. 法令または公序良俗に反すること
2. 本サービスのサーバーやネットワークに過度な負荷をかけること（自動化された大量の問い合わせなど）
3. 本サービスの仕組みを不正に操作すること、他人になりすますこと
4. 本サービスから得たデータを、元のデータの使用許諾（ODbL）に反して使うこと
5. その他、運営者が不適切と判断すること

## 5. 本サービスの変更・停止

運営者は、事前の通知なく、本サービスの内容を変えたり、提供を止めたりすることがあります。止める場合は、できるだけ事前に本サービスの画面や下の連絡先でお知らせします。

## 6. 免責

1. 運営者は、本サービスの情報の正確さ・最新さ・完全さを保証しません。
2. 本サービスを使ったこと、または使えなかったことで利用者に損害が生じた場合、運営者は、運営者の責めに帰すべき事由があるときに限り、賠償します。
3. 前項の場合で、運営者に故意または重大な過失が無いときは、賠償は利用者に**直接かつ通常生じた損害**に限ります。運営者に故意または重大な過失があるときは、この制限を適用しません。
4. 本サービスは、AI アシスタント・Google・Cloudflare・OpenStreetMap など外部のサービスの上で動いています。それらの不具合や仕様の変更によって生じた損害で、運営者の責めに帰すべき事由が無いものについて、運営者は責任を負いません。

## 7. 規約の変更

1. 運営者は、次のどちらかにあたるときに限り、利用者の個別の同意を得ずに本規約を変更できます（民法 548 条の 4）。
   1. 変更が利用者の一般の利益に合うとき
   2. 変更が本規約の目的に反せず、変更の必要性、変更後の内容の相当性、その他の変更にかかわる事情に照らして合理的なとき
2. 変更するときは、**変更が効力を生じる日より前に**、変更すること・変更後の内容・効力を生じる日を、このページで知らせます。
3. 1. の 2. にあたる変更（合理的な変更）は、効力を生じる日までに 2. のとおり知らせなければ効力を生じません。

## 8. 準拠法・裁判管轄

本規約は日本の法律に従って解釈します。本サービスに関して争いが生じた場合は、【運営者の所在地を管轄する地方裁判所】を第一審の専属的合意管轄裁判所とします。
