# 規約

プライバシーポリシー（[privacy-policy.md](privacy-policy.md)）と利用規約（[terms.md](terms.md)）の正本。
**`https://iekeiramen.com/privacy` と `/terms` で公開している**（#198、2026-10-12）。ビルドのときに
`scripts/build/legal-markdown.mjs` が HTML にし、`scripts/build/seo-pages.mjs` の `legalPages` がほかの静的なページと同じ
ヘッダー・フッター・タブバーで包む。`【` が残っているとビルドが止まる。ディレクトリへの掲載の申請（#47）に要る。

**Markdown の書式は、`legal-markdown.mjs` が読むもの（見出し・段落・表・箇条書き・太字・コード・リンク）だけを使う。**

**文面はコードの実際の振る舞いと揃えてある。** 次のどれかを変えたら、ここも直すこと。

| 変えたもの                                                                                       | 直す箇所          |
| ------------------------------------------------------------------------------------------------ | ----------------- |
| 保存するもの（D1 の `visits`、KV、Analytics Engine に書く欄）                                    | ポリシー 2.       |
| サインインで要求する範囲（今は `openid` だけ）                                                   | ポリシー 1.・2.2  |
| OAuth のライブラリの設定（トークンや登録の有効期限・Cookie・`/register` で受ける欄）             | ポリシー 2.2・2.3 |
| 外部に送る先（`uiResourceMeta` の CSP・Nominatim・地図アプリへのリンク・新しい外部 API）         | ポリシー 4.       |
| 利用回数に書く欄（`server/lib/usage.ts` の `toDataPoint`）                                       | ポリシー 2.3      |
| 家系判定の段階の名前（`CONFIDENCE`）・味の傾向の出し方                                           | 規約 2.           |
| Cookie（今はサインインの手続き中の `__Host-oauth-*` だけ）                                       | ポリシー 2.2      |
| Cloudflare Web Analytics（ダッシュボードの設定でエッジが全ページに埋め込む。リポジトリには無い） | ポリシー 2.3・4.  |
| 端末に残すもの（`localStorage` のキー）・診断の回答・家系カメラの写真の扱い                      | ポリシー 2.4      |
| 共有の先（X・Threads）・地図アプリへのリンク                                                     | ポリシー 4.       |
| 機能（Web だけ・会話の中だけの区別を含む）                                                       | 規約 1.・3.       |

**使い始める前に規約が目に入るようにする**（民法 548 条の 2）。規約の文面だけでは、読まずに使い始めた人に効かない。
Web のすべてのページの下（`src/utils/legal-links.ts`）と `/connect` のフッターからリンクしている。ディレクトリの
掲載ページにも 2 つの URL を載せる（#47）。

裁判所は東京地方裁判所（オーナーの判断）。運営者の住所は載せず、問い合わせに遅滞なく答える形にしている（個人情報保護法 32 条）。住所を聞かれたら答えられるようにしておくこと。連絡先の `support@iekeiramen.com` は Cloudflare の Email Routing で転送している。
