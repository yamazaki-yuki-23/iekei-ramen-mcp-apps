**公開するときは、使い始める前に規約が目に入るようにする**（民法 548 条の 2）。規約の文面だけでは、
読まずに使い始めた人に効かない。ディレクトリの掲載ページ・Web 版・アプリの画面（初回の表示やフッターなど）の
どこで示すかは、公開する場所と一緒に決める（#34 の後）。

公開前に【】の部分（公開日・裁判所）を埋める。運営者の住所は載せず、問い合わせに遅滞なく答える形にしている（個人情報保護法 32 条）。住所を聞かれたら答えられるようにしておくこと。連絡先の `support@iekeiramen.com` は Cloudflare の Email Routing で転送している。
