# プライバシーポリシー

制定日: 【公開日】

「家系ラーメンを探す」（以下「本サービス」）は、Claude・ChatGPT などの AI アシスタントの中で家系ラーメンの店を探せるアプリです。本サービスの運営者である山﨑悠樹（以下「運営者」）は、利用者の情報を次のとおり扱います。

## 1. 要点

- **検索・地図・「迷ったら」「まわる店」は、サインインせずに使えます。** このとき、利用者を識別する情報は保存しません。
- **サインインが要るのは「行った」の記録（訪問スタンプ）だけです。** 保存するのは、利用者ごとの識別子（Google のアカウント ID を変換したもの）と、行った店と、その日時です。
- 利用者のメールアドレス・氏名・プロフィール写真は受け取りません。
- 情報を販売したり、広告に使ったりしません。

## 2. 受け取る情報と使い道

### 2.1 サインインせずに使うとき

| 情報                                                   | 受け取り方                                                                                                                        | 使い道                                                            | 保存                                                                                                                                |
| ------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| 検索の条件（都道府県・地名・味の好み・地図の範囲など） | AI アシスタントが本サービスの機能を呼ぶときに送る                                                                                 | 店を探して結果を返す                                              | 保存しない                                                                                                                          |
| 地名で探したときの地名                                 | 同上                                                                                                                              | 地名を緯度経度に直す（下の 4. の OpenStreetMap Nominatim に送る） | 同じ地名の問い合わせを減らすため、**地名の検索結果**を最大 7 日間保存する。保存の鍵は地名を変換した値で、誰が探したかは結び付けない |
| 端末の正確な現在地                                     | 「現在地から探す」で、利用者が端末の位置情報の利用を許可したとき（端末が出せるいちばん正確な緯度経度）                            | 近い店を探す                                                      | 保存しない                                                                                                                          |
| おおよその現在地                                       | 端末の位置情報が使えないとき。AI アシスタントが添える市区町村程度の位置、または接続元の IP アドレスから Cloudflare が推定する位置 | 近い店を探す                                                      | 保存しない                                                                                                                          |
| 接続元の IP アドレス                                   | 通信に伴って届く                                                                                                                  | 同じ接続元からの短時間の大量の地名検索・店舗情報の報告を止める    | 制限の判定のために一時的に使い、本サービスの記録には残さない                                                                        |

店舗情報の報告はサインインせずに送れます。既存店舗については店舗のIDと報告の種類を、
未掲載の店舗については店名と場所を、受付日時・報告IDとともに保存します。
用途は店舗データの訂正の確認だけです。個人情報は記入しないでください。
処理した報告は採用・見送りとも削除します。未処理でも受付から30日を過ぎた報告は、
次に新しい報告を受け付ける際に削除します。報告が来なければ削除まで残ります。
公開する訂正の記録には店舗のID・判断・運営側が書いた理由だけを残し、自由記述をそのまま載せません。

### 2.2 サインインして「行った」を記録するとき

| 情報                                                          | 受け取り方                                                  | 使い道                                                                                                       | 保存                                                                                                                                                |
| ------------------------------------------------------------- | ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Google のアカウント ID（`sub`）                               | Google でサインインしたとき（要求する範囲は `openid` だけ） | 利用者を見分ける                                                                                             | **そのままは保存しない。** 運営者だけが持つ鍵で一方向に変換した値（利用者の識別子）にして保存する                                                   |
| 行った店と日時                                                | 「行った」を押したとき                                      | 行った店の一覧・制覇率を表示する                                                                             | 利用者の識別子と組にして、**利用者が削除するまで**保存する（3. を参照）                                                                             |
| サインインの状態（アクセストークンなど）                      | サインインの手続きの中で発行する                            | 「行った」の記録を本人だけが読み書きできるようにする                                                         | 有効期限まで保存する（アクセストークンは 1 時間、更新用のトークンは 30 日。更新用のトークンが有効な間は、サインインし直さずに記録を読み書きできる） |
| サインインの手続き中の Cookie（`__Host-oauth-` で始まるもの） | サインインを始めたとき、利用者のブラウザに置く              | サインインの手続きを、始めたのと同じブラウザで終えたことを確かめる（なりすまし対策）。広告や追跡には使わない | 最長 10 分。手続きが終わるか期限が来ると使えなくなる                                                                                                |

### 2.3 どちらの場合も

| 情報                                                                                                      | 受け取り方                                                                                                              | 使い道                                                           | 保存                                                                                                                                     |
| --------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 呼ばれた機能の名前・呼ばれた日時と、サインインしているかどうか（「行った」のときは、押したか外したかも）  | 本サービスが機能を受け付けたとき                                                                                        | 機能ごとの利用回数を週ごとに数え、改善に使う                     | 3 か月保存する（保存先の Cloudflare Analytics Engine の保存期間）。**検索の条件・地名・位置・IP アドレス・店・利用者の識別子は含めない** |
| AI アシスタントの登録情報（アプリの名前・戻り先の URL、送られてくれば提供元の連絡先のメールアドレスなど） | AI アシスタントが、サインインに使うために本サービスへ自分を登録するとき（利用者ではなく AI アシスタントの提供元の情報） | サインインの手続きで、どの AI アシスタントからの要求かを確かめる | その AI アシスタントが最後に使われてから最長 90 日保存する（使われ続けている間は期限が延びる）                                           |

## 3. 利用者ができること

- **記録の削除:** AI アシスタントに「記録を消して」と頼むと（`forget-my-iekei-ramen-visits`）、その利用者の訪問記録をすべて削除します。1 軒ずつ「行った」を外すこともできます。
- **連携の解除:** Google アカウントの設定から、本サービスとの連携を解除できます。本サービスが発行したトークンは、有効期限（最長 30 日）が来ると使えなくなります。解除しても訪問記録は残るので、消したいときは先に削除してください。
- **開示などの請求:** 下の 8. の連絡先へご連絡ください。

## 4. 外部への送信と委託

本サービスは、次の事業者のサービスを使って動いています。

| 事業者                           | 使い方                                                                    | 送る情報                                                                                                                                                                                                                                                                                                          |
| -------------------------------- | ------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Cloudflare, Inc.（米国）         | 本サービスの実行・データの保存（Workers・D1・KV・Analytics Engine）・通信 | 本サービスへの通信のすべて。障害の調査のため、Cloudflare の仕組みで通信の記録（日時・接続先・応答など）が Cloudflare の定める期間残ります                                                                                                                                                                         |
| Google LLC（米国）               | サインイン                                                                | サインインの手続きに必要な情報（利用者は Google の画面でサインインし、運営者はパスワードを受け取りません）                                                                                                                                                                                                        |
| Google LLC（米国）               | 「まわる店」の順路を Google マップで開く（利用者が押したときだけ）        | 出発点と、まわる店の緯度経度。出発点は、「現在地から探す」で端末の位置情報を許可した場合は**端末の正確な現在地**になります。Google マップを開くリンクに入れて、利用者の端末から Google に送ります。本サービスのサーバーは送りません                                                                               |
| OpenStreetMap Foundation（英国） | 地名から緯度経度への変換（Nominatim）・地図の画像                         | 地名の変換: 地名の文字列だけ（本サービスのサーバーから送り、利用者の IP アドレスは送りません）。地図の画像: 利用者の端末が直接読み込みます。このとき、**表示している地図の範囲**（位置と拡大率）と、端末の IP アドレスなどが OpenStreetMap に届きます。現在地の近くを表示していれば、おおよその居場所が伝わります |
| OpenStreetMap Foundation（英国） | 選んだ店を地図で開く（利用者が押したときだけ）                            | その店の緯度経度。OpenStreetMap を開くリンクに入れて、利用者の端末から送ります。どの店を選んだかが OpenStreetMap に伝わります                                                                                                                                                                                     |

利用者が使っている AI アシスタント（Anthropic の Claude、OpenAI の ChatGPT など）は、会話と本サービスへの呼び出しをそれぞれの事業者の方針で扱います。本サービスの結果は会話に表示され、AI アシスタントの事業者にも届きます。

上の事業者の一部は日本国外にあります。各国の個人情報の保護の制度は、個人情報保護委員会の「外国における個人情報の保護に関する制度」をご覧ください。

## 5. 第三者への提供

法令に基づく場合を除き、利用者の情報を第三者に提供しません。

## 6. 安全管理

- Google のアカウント ID は保存せず、変換した値だけを保存します。
- 訪問記録は、サインインした本人のアクセストークンでしか読み書きできません。
- 通信は HTTPS で暗号化します。

## 7. 子どもの利用

本サービスは、13 歳未満の方を対象としていません。
